This repository contains material for the baseball paper "Contact, Power, and Balls in Play:
A Three-Rate Decomposition of Batting Averageand the Disappearance of the .400 Hitter" created with the help of the AI program Claude.

- paper.pdf contains the paper written in the style of an academic journal such as JQAS
- analysis.R contains all of the R code for reproducing the calculations and graphs in the paper
- app.R is a Shiny app that illustrates the ideas of the paper using data from the Lahman R package
